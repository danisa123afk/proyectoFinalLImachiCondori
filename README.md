# Simulador de Impacto Económico Familiar - Crisis Actual Bolivia

### Descripción del Proyecto
Una aplicación educativa que te ayuda a calcular cómo la subida de precios afecta el presupuesto familiar en los hogares bolianos, con la crisis actual
### Escenarios Desarrollados
* Módulo B:Variación e Incremento en Precios de Alimentos básicos.
* Módulo D: Balance de Presupuestos y Compras familiares críticas.
* Módulo F:Pérdida Porcentual del Poder Adquisitivo Familiar.

### Tecnologías Utilizadas
* HTML5 (Estructuración semántica)
* CSS3 (Grid, Flexbox y media queries para soporte móvil)
* JavaScript Vanilla (Manipulación dinámica del DOM y lógica matemática)
